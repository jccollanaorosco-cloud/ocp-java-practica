# Capitulo 1 - Java Building Blocks

Carpetas numeradas (_01_, _02_...) para que aparezcan en el ORDEN DEL LIBRO.
El guion bajo delante del numero es obligatorio: un paquete Java no puede
empezar por un digito, asi la carpeta y el 'package' coinciden.

Cada tema es un paquete: dentro puedes meter todas las clases Java que quieras.

## Abrir en VS Code
1. Descomprime el ZIP.
2. File -> Open Folder -> abre la carpeta RAIZ `cap01-java-building-blocks`.
3. Instala el JDK y la extension "Extension Pack for Java" (Microsoft).

## Ejemplo que ya corre
_01_java_class_structure/_01_fields_and_methods/  -> Animal.java + Main.java
Abre Main.java y pulsa Run. Imprime: El animal se llama: Firulais

## Agregar tu codigo
Clic derecho en la carpeta del tema -> New Java Class.
La primera linea (package ...) debe coincidir con la ruta de la carpeta.
